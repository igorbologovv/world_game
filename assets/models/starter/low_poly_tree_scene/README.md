# Low Poly Tree Scene Free

This scene by Nicholas-3D is licensed under CC BY 4.0. The original source
link and attribution are in [LICENSE.txt](LICENSE.txt).

The runtime GLB groups meshes by material and embeds the original textures.
The packer lowers the detached sample objects to the terrain datum and adds a
soil edge beneath the pond perimeter to meet the landscape.

Rebuild it from the downloaded `low_poly_tree_scene_free/` folder at the
checkout root with NumPy and Pillow installed.

```sh
python3 tools/pack_starter_tree_scene.py
```
