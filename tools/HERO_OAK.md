# Hero Oak

A large, organic oak with tapered, curved trunk and branches, visible roots,
procedural bark, double-sided leaf-card foliage with RGBA cutout, and four LODs.
All textures and geometry are generated by the script; no external assets.

## Files

| Generator output | Geometry |
|---|---:|
| `oak_lod0.glb` | 33,524 triangles |
| `oak_lod1.glb` | 4,384 triangles |
| `oak_lod2.glb` | 626 triangles |
| `oak_lod3.glb` | 8 triangles (two double-sided cross cards) |

GLB files contain embedded color and alpha textures. They are **Y-up**
(gltf convention) and roughly 22 metres tall; the root is at the origin.

## Generate or edit in Blender (Blender 4.x)

```bash
# Arch Linux
sudo pacman -S blender

# Generate GLB and editable hero_oak.blend with selectable LOD models
blender -b --python build_hero_oak.py -- --output ./hero_oak
```

In Blender UI you can also switch to **Scripting** and run the contents of
`build_hero_oak.py` (adjust `--output` appropriately). The four models are
separate Blender meshes. LOD0 stays visible; other LODs are hidden.

Standalone generator (without Blender, requires `trimesh` and `Pillow`):

```bash
python build_hero_oak.py --output ./hero_oak
```

This creates all GLBs and texture PNGs, **not** a `.blend` file. A separate
preview PNG was generated by a local 3D viewer for inspection.

Different deterministic variants:

```bash
blender -b --python build_hero_oak.py -- --output ./oak_variant_2 --seed 18203
```

## Bevy runtime

The client loads three meshes from `assets/models/hero_oak/`. The runtime
mesh budgets are 33,524, 17,803, and 14,280 triangles. The original generator
also exports cross cards for standalone previews. The client uses the shared
multi-view atlas for both leaf and parent forest batches.

To update the runtime tree, install the regenerated canonical
`oak_lod0.glb`, then rebuild the simplified GLBs and the atlas.

```sh
blender -b --python-exit-code 1 --python tools/build_tree_lods.py
cargo test --locked -p world-vegetation bake_tree_impostors -- --ignored
```

The runtime mesh LODs share bark and foliage textures, foliage clips at 0.46,
and the foliage shader uses the same wind weights for each mesh level.
See the [vegetation crate](../crates/world-vegetation/README.md) for distance
bands and verification commands.

## Notes

- Each file is an **original** tree model generated locally, not a purchased
  asset or copy of someone else's game art.
- Blender back-end was authored but **not executed** in this environment;
  the prebuilt GLBs were exported with the standalone fallback and reloaded
  and rendered with a separate 3D viewer.
- Preview lighting is illustrative, not a test of Bevy's PBR renderer.
- The source exports contain geometry and textures. The client supplies wind through its foliage shader.
